## Reddit gönderisi (r/opensource, r/software, r/Turkey bilim-teknoloji; kurallarını kontrol et)
Başlık: [Open source] ElfCaesar Studio – an offline Windows app for encryption, a password vault and a phishing-aware browser extension
Metin:
I've been building ElfCaesar Studio, a free (MIT) Windows app that works completely offline: AES-256-GCM file/folder vaults,
end-to-end encrypted messages you can paste into WhatsApp/Telegram, Ed25519 signatures, and a password vault with a browser
extension (Chrome/Edge/Brave/Opera/Firefox) that only fills on the exact domain and warns on look-alike phishing domains.
No account, no server, no telemetry. It's in beta and I'd love blunt feedback — especially on the security design.
Site & video: https://mcemkoca.github.io/elfcaesar-studio/
Code: https://github.com/mcemkoca/elfcaesar-studio
Note: the installer is signed with my own certificate (open-source signing application pending), so SmartScreen will warn;
releases include an Ed25519-signed SHA256SUMS and a VirusTotal link.
