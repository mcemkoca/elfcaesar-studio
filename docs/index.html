“Windows bilgisayarınızı korudu” uyarısı

Kurulum dosyası Dante'nin kendi sertifikasıyla imzalıdır. Windows bu sertifikayı henüz tanımadığı için SmartScreen uyarısı görebilirsin: Ek bilgi → Yine de çalıştır. Kurmadan önce dosyanın bizden geldiğini doğrulayabilirsin:

pip install cryptography
python verify_release.py SHA256SUMS.txt SHA256SUMS.txt.sig
