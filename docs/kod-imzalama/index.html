ELFCAESAR STUDIO

Code signing policy

Kod imzalama politikası — Türkçe özet en altta.

Free code signing for Windows releases is provided by SignPath.io, certificate by SignPath Foundation. Status: application submitted; until it is approved, releases are signed with the maintainer's own certificate (publisher “Dante”) and every release carries an Ed25519-signed SHA256SUMS.txt (release key fingerprint B715 8370 19A2 935F).

What is signed

Only binaries built from this repository's source code by GitHub Actions: ElfCaesarStudio.exe, ElfCaesarNativeHost.exe and ElfCaesarStudio-<version>-Setup.exe. Third-party components (Python runtime, cryptography) are not signed by us.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. The only optional online feature (password leak check) sends the first 5 characters of a SHA-1 hash to api.pwnedpasswords.com after an explicit confirmation. Full policy: Gizlilik politikası.

Uninstall

Windows Settings → Apps → ElfCaesar Studio → Uninstall. Your encrypted files and vaults are left untouched.

Türkçe özet

Windows sürümleri için ücretsiz kod imzalama SignPath.io tarafından sağlanır, sertifika SignPath Foundation adına düzenlenir (başvuru değerlendirmede). O zamana kadar sürümler Dante sertifikası ve Ed25519 imzalı SHA256SUMS.txt ile yayımlanır. Yalnızca bu depodan GitHub Actions ile derlenen dosyalar imzalanır; her imza talebi elle onaylanır. Program, kullanıcı açıkça istemedikçe hiçbir bilgiyi başka sistemlere göndermez.
